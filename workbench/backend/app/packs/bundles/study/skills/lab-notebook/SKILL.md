# Lab notebook

Use this when the user records an experiment, observation, method or result.

1. Call study_lab_entry with a title, the body (method, observations, results) and any file ids to attach.
2. Entries are dated when they are created. Changes are kept as amendments, so the original record stays readable.
3. Offer to export the notebook as PDF, Markdown or JSON from the Study page.
