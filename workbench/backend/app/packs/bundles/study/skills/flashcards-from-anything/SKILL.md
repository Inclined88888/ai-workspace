# Flashcards from anything

Use this when the user wants to study, revise or memorise material from a file, lecture notes or a chapter.

1. Call study_make_flashcards with the file id (or the pasted text) and a deck name. Each card keeps its source location.
2. Tell the user how many cards were made and that they can review them on the Study page, where due cards come back on a
   spaced-repetition schedule.
3. To quiz in chat, ask one card at a time and let the user answer before showing the back.
