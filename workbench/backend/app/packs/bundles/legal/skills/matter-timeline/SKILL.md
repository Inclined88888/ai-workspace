# Matter timeline

Use this when the user wants a chronology of events from letters, emails, contracts or court documents.

1. Call legal_timeline with the file ids. Dates are read day first (Australian style) unless the user's settings say otherwise.
2. Show the entries in date order with the source of each one. Flag entries where the date was ambiguous.
3. Offer to export the timeline as a Word document or add key deadlines to the calendar (the user confirms each event).

This is a reading aid, not legal advice. The user should check every date against the original document.
